## 六、检索强制规则

1. **卷号从正文卷题解析，不使用 `chapterN` 作为卷号。**
2. `DUPLICATE_EXACT` 只索引首个副本，防止重复案例提高虚假相关度。
3. `MISSING_CONFIRMED` 不进入“无记载”判断。
4. 重要案例输出前必须检查该卷的 `source_integrity`。
5. 柏杨译文仅作为理解层；司马光原文、史家“臣光曰”、现代译文分层存储。
6. 若现实检索命中缺卷年代，而《史记》有对应材料，可以使用用户指定的维基文库《史记》作为**独立来源**；不得假称补齐了《资治通鉴》原文。
