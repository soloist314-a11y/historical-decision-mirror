## 16. v0.7 二级机制深化

### 16.1 授权与撤权必须分开设计

授予权限时必须提前记录：
1. 资源所有权与运营权是否分离；
2. 独立信息接口；
3. 撤权触发条件；
4. 数据、客户、团队与合同的移交义务；
5. 过渡期安排；
6. 撤权后谁能继续履约。

不得把“现在可以授权”自动推导为“未来可以低成本撤权”。

### 16.2 第二权力中心识别

出现以下任一组合时，应检索 `second_power_center`：
- 私人接近权 + 正式人事权；
- 地域控制 + 独立现金流 + 团队；
- 事实资源控制 + 名义职位；
- 交班后旧领导继续掌握关键影响力；
- 上级持续追加正式合法性资源给已事实独立者。

输出必须先判断第二中心的资源来源，而不是直接评价其忠诚度。

### 16.3 合作方锁定

对关键合作至少建立六项 Lock-in 账：
- 资产；
- 客户；
- 团队；
- 数据/知识；
- 地域/渠道；
- 时间窗口与专用投资。

每项分别记录：所有权、运营权、可撤回性、撤回需对方配合程度、替代时间和违约后的继续经营能力。

### 16.4 沉没成本与继续投资

如果理由中出现“已经投了很多”“不能认输”“会被笑”“必须证明过去判断正确”，标记为沉没成本/声誉污染候选，但不得因此直接建议停。

必须重新构造 **从现在开始** 的决策：
- 未来新增成本；
- 未来增量收益；
- 成功概率的新信息；
- 替代方案；
- 退出价值；
- 继续投入对未来选择权的影响。

历史上“加码后来成功”也不能反证加码当时必然正确。

### 16.5 项目停损 Gate

重大项目建议预先定义：
- G1 核心假设证伪；
- G2 时间里程碑；
- G3 成本/现金流上限；
- G4 外部条件变化；
- G5 关键资源机会成本；
- G6 替代路线是否成熟；
- G7 剩余选择权；
- G8 继续决策是否被沉没成本/声誉污染。

没有事前 Gate 时，历史案例只能提醒“重新评估”，不能替用户生成任意停损线。

### 16.6 强势上级错误指令

必须把两个问题分开：
1. **Task correctness**：指令本身的事实与专业依据；
2. **Dissent cost**：提出异议、拒绝或升级处理的组织/职业成本。

现代优先路径：书面风险说明 → 替代方案 → 权限边界确认 → 独立评审/升级 → 合规渠道。

不得把周亚夫、白起等军事案例转化为“违令模板”。

### 16.7 关键人才留退

挽留/重新定级至少检查：
- 已验证实绩；
- 多源评价；
- 稀缺性；
- 替代时间与成本；
- 岗位适配；
- 授权能否匹配责任；
- 内部公平；
- 离职原因是否能结构性解决。

“提出离职”本身不构成关键人才证据。

项目失败后的人员决策必须区分：
- 战略层决策错误；
- 执行层可控失误；
- 能力不足；
- 重大过失/合规问题。

### 16.8 代理背叛不得用人格解释替代结构分析

检索到背叛案例时，优先检查：
- 激励是否逆转；
- 人身/职业安全是否恶化；
- 代理人是否获得替代联盟；
- 主体是否失去制衡资源；
- 信息入口是否被代理垄断；
- 长期不公平是否累积。

历史暴力、谋杀、欺骗行为只能用于理解风险形成机制，不能迁移为现实行动方案。

- `failure_accountability_separation`
- `talent_underrecognition_loss`
