# 历史抉择镜鉴 · Historical Decision Mirror

用可回链的历史决策节点辅助现实选择，检查错误类比、制度差异与事后偏见。v1.0 将原 v0.9 的 110 个 ACTIVE 节点、3 个 DEPRECATED 节点和 15 组对照迁入可维护的技能工程；不增加新案例。

## 唯一入口

```text
/历史推演 [quick|deep|audit] <现实问题>
```

默认 deep。quick 压缩呈现，deep 完整推演，audit 检验用户已有判断。自然语言“调用历史抉择镜鉴：……”或“用资治通鉴推演……”进入同一流程。

中文斜杠写法是稳定的输入约定，不声称所有宿主自动注册同名菜单。支持 SKILL.md 的宿主应加载本目录；脚本也能直接解析同一输入。宿主自动选择技能时由 description 识别自然语言意图，未被脚本词面规则识别的请求由宿主按同一约定转交。

## 本地运行

Python 3.9+：

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
python scripts/runtime.py '/历史推演 audit 我准备交班，是否应由继任者重新确认关键高管授权？'
python scripts/run_evals.py
```

runtime 返回请求、结构特征、候选及反案例，**不是完整的自动决策回答**。最终推演由加载技能的宿主完成现实结构化、六道准入审计、原文回读和条件树。排名不证明角色同构，旧 SOURCE_VERIFIED 标记不等于本次已读取证据；零结构特征会明确停止类比。

## 验证

统一入口 `scripts/run_evals.py` 执行原测试和新增约束测试。离线执行不冒充当次原文复核。

```sh
# 指定合法持有且解包到发布目录之外的 EPUB；维基文库缓存也放在目录外
python scripts/run_evals.py --epub-ops /private/path/OPS --cache /private/path/wikisource --refresh
```

v1.0 本地自动检查：207/207（包含 113 条来源引用锚点）；原召回 Top-1/Top-3 10/10、对照 8/8、端到端 5/5、旧回归 18/18 均保留。锚点检测只证明指定文本位置至少有一个分句匹配，不认证整个历史解释或现代建议。全部本次原文下载缓存保留本地，不打包。

独立模型还运行六项合成负测试，结果与方法单列在 reports/behavioral_review.json，不算入自动测试数。它不是生产宿主集成测试，也不是用户真实决策盲测。真实问题由用户后续自行运行。
